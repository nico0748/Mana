# src/components/books/

書籍管理機能の中核をなすコンポーネント群を格納するディレクトリ。書籍の一覧表示・詳細表示・追加・編集・削除・バーコードスキャンを担う。

## ファイル

### `BookList.tsx`

書籍管理のメインページコンポーネント。書籍の一覧表示と各種操作のエントリーポイント。

**機能:**
- `useBooks()` フックから書籍データと CRUD 関数を取得（React Query）
- テキスト検索（タイトル・著者名・サークル名・タグ）
- 書籍種別フィルタリング（全て / 商業本 / 同人誌）
- タグフィルタリング
- ソート（登録日時 / タイトル / 著者 / NDC コード）
- 「本を追加」ボタンクリックで `BookForm` モーダルを表示
- 書籍カードクリックで `BookDetailModal` を表示

**使用箇所:** `src/App.tsx`（`/` ルート）

---

### `BookItem.tsx`

個別の書籍を表示するカードコンポーネント。

**Props:**
| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `book` | `Book` | 表示する書籍データ |
| `onClick` | `() => void` | カードクリック時のコールバック |

**表示内容:**
- 書影画像（未設定時はプレースホルダー）
- タイトル・著者・サークル名
- 書籍種別バッジ（商業 / 同人誌）
- 所有状態バッジ
- タグ一覧

---

### `BookForm.tsx`

書籍の新規追加・編集を行うフォームコンポーネント。セクション分けと種別連動表示に対応。

**Props:**
| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `initialData` | `Book \| null` | 編集時の初期値。`null` なら新規追加モード |
| `onSubmit` | `(data, file?) => void` | フォーム送信時のコールバック |
| `onCancel` | `() => void` | キャンセル時のコールバック |
| `defaultType` | `BookType` | 初期種別（本棚フィルタから自動セット） |

**フォームフィールド（種別連動）:**
- 共通: タイトル・著者・種別・ステータス・価格・カバー画像・メモ
- 商業誌のみ: ISBN・カテゴリ・NDCコード
- 同人誌のみ: サークル名・タグ

**追加機能:**
- ISBN フィールド横「スキャン」ボタンで `BarcodeScanner` を起動
- ISBN 入力後「取得」ボタンで `fetchBookByIsbn()` を呼び出しフォームを自動補完
- タイトル入力後「書影を検索」ボタンで複数候補から書影 URL を選択

### `BookDetailModal.tsx`

書籍詳細を表示するモーダルコンポーネント。

**Props:**
| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `book` | `Book` | 表示する書籍データ |
| `onClose` | `() => void` | モーダルを閉じるコールバック |
| `onUpdate` | `(id, data, file?) => void` | 書籍更新時のコールバック |
| `onDelete` | `(bookId) => void` | 書籍削除時のコールバック |

**機能:**
- 書籍の全フィールドを整形して表示
- 編集モードへの切り替え（`BookForm` をインラインで表示）
- アフィリエイトリンク（Amazon 等）の生成・表示

---

### `BarcodeScanner.tsx`

カメラを使って ISBN バーコードをスキャンするモーダルコンポーネント。

**Props:**
| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `isOpen` | `boolean` | モーダルの表示状態 |
| `onScan` | `(isbn: string) => void` | スキャン成功時のコールバック |
| `onClose` | `() => void` | モーダルを閉じるコールバック |

**動作:**
1. カメラ映像をモーダル内に表示
2. `react-zxing` の `useZxing()` フックでリアルタイムにバーコードを検出
3. ISBN が読み取れたら `onScan(isbn)` を呼び出してモーダルを閉じる
4. 閉じるとカメラストリームを停止

**依存:** `react-zxing`
