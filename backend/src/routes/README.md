# backend/src/routes/

API エンドポイントをリソースごとに分割した Express ルーターを格納するディレクトリ。

全ルーターは `authenticate` ミドルウェア通過後に実行される。`(req as any).uid` でログインユーザーの Firebase UID を取得し、自分のデータのみを操作する。

## ファイル

### `books.ts` — `/api/books`

書籍データの CRUD。

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/` | ログインユーザーの書籍一覧を `createdAt` 降順で取得 |
| POST | `/` | 書籍を新規作成（`userId` を自動付与） |
| PUT | `/:id` | 書籍を更新（所有者チェックあり） |
| DELETE | `/:id` | 書籍を削除（所有者チェックあり） |

---

### `events.ts` — `/api/events`

| メソッド | パス | 説明 |

| GET | `/` | ログインユーザーのイベント一覧 |

### `circles.ts` — `/api/circles`

即売会サークルの CRUD。

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/` | ログインユーザーのサークル一覧 |
| POST | `/` | サークルを新規作成 |

| DELETE | `/:id` | サークルを削除 |
