# docs/

プロジェクトのドキュメント・設計メモ・作業キューを格納するディレクトリ。

## ファイル

### `next.md`

Claude Code との作業キューファイル。未対応・対応済みのタスク一覧を管理する。

**フォーマット:**
- `[ ]` — 未対応タスク
- `[x]` — 対応済みタスク（対応済みセクションに移動済み）

**凡例:**
| ラベル | 内容 |
|---|---|
| `[bug]` | バグ修正 |
| `[feat]` | 新機能 |
| `[fix]` | 既存機能の改修 |
| `[chore]` | 設定・リファクタリング |
| `[test]` | テスト |

作業完了後は必ずブランチを切り、PR を作成して `main` にマージする運用を取る。
